# Brand assets

Drop Pink Rabbit brand files here — logos, wordmarks, icons, brand colours,
fonts, product shots used as furniture rather than ad creative.

Anything in this folder is committed to the repo and served by the live site,
so it can be referenced from `index.html` as `assets/<filename>`.

Preferred formats:
- Logo / wordmark: SVG first, transparent PNG at 2x as fallback
- Favicon source: square PNG, 512x512 or larger

Ad artwork goes in `../creative/` instead.
